# Barcode 工具站中文开发文档包

包含：

- AGENTS.md
- docs/prd-mvp.md
- docs/task-list.md
- docs/acceptance.md

使用方式：

1. 将 `AGENTS.md` 放到项目根目录。
2. 将 `docs/` 目录复制到项目根目录。
3. 如果使用 Claude Code，建议复制一份 `AGENTS.md` 并命名为 `CLAUDE.md`，或者在 `CLAUDE.md` 中引用 `@AGENTS.md`。
4. 让 Codex / Claude Code 按 `docs/task-list.md` 逐个任务执行，不要一次性开发完整 MVP。
